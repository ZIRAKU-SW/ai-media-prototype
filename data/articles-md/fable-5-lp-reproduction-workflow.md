## デザイン画像1枚から、動くLPができる時代

「LPのデザイン案はあるが、コーディングする人がいない」──中小企業や1人社長のWeb制作で最も多い詰まりポイントです。スモビジ開発ラボ(@yoshio_nocode)氏が公開した検証が、この常識を変えるかもしれません。

氏は画像生成AIで作ったLPデザイン画像をClaude Fable 5に渡し、**Next.js(Webアプリのフレームワーク)で再現させたところ、一致度が圧倒的だった**と報告しています。GPT-5.5でも同じことを試した上で「全然一致度が高い」、さらに「マーケ戦略脳と文章力も強い」という評価です。

## 推奨ワークフロー: 役割分担で組む

氏が勧める構成は、**LP制作の基盤はClaude Codeに任せ、画像生成だけCodex(画像生成AI)を呼び出す**分業です。コーディングと文章はClaude、ビジュアル素材は画像生成AI──それぞれの得意分野に振り分けます。

実際に使われたプロンプトがこちらです(そのまま試せます)。

```
/goal 添付画像のLPをNext.jsで実装。再現度95%以上になるまで。
画像以外の手段だと再現が難しそうな箇所は適切に素材をimage_genで
画像生成しながら作成して。

- アイコンや画像はなるべく元の画像と一致させること。
  元画像から該当部分をクロップして参考画像としてimage_genに渡しつつ生成する
- レスポンシブ対応すること。375〜1440pxの各幅で検証し、
  横スクロールがないだけでなく、要素の重なり・見切れもないこと
- Playwrightでスクショ→元画像と比較→修正のループを回し、
  npm run build が通ったら完了
```

## このプロンプトがうまい3つの理由

短いプロンプトですが、AIに長時間の自律作業をさせるコツが詰まっています。

**1. ゴールを数値で渡している** — 「いい感じに作って」ではなく「再現度95%以上になるまで」。AIが自分で合否判定できる基準があると、勝手に修正ループを回し続けます。

**2. 検証方法まで指定している** — 「スクショを撮って元画像と比較して修正するループを回せ」。作りっぱなしではなく、自己チェックの手順そのものを指示に含めています。

**3. 素材の作り方まで設計している** — 再現が難しい画像部分は「元画像から該当部分を切り出して参考画像として渡しながら生成」。デザインの一貫性を保つ実務的な工夫です。

これは実は、LP制作に限らない**「AIへの仕事の任せ方」の型**です。①数値ゴール ②自己検証の手順 ③困ったときの代替手段、の3点セットで渡すと、AIは人間の細かい指示待ちをせずに完成まで走れます。

## 中小企業にとっての意味

外注すると数十万円かかるLP制作が、「デザインイメージを用意する→プロンプトと一緒に渡す→検証ループを回させる」だけで形になる可能性が出てきました。もちろん最終的な品質確認・公開判断は人間の仕事ですが、**初稿までの時間とコストが桁で変わる**インパクトがあります。

自社サービスの紹介ページやキャンペーンLPなど、「作りたいが後回しにしていた」ページから試してみる価値があります。
