## カテゴリ別 — 再発時にまず見る場所

### 1. モバイル記事カード（最多・重要）

| # | タイトル | テーマ | 対策の要点 |
|---|---------|--------|-----------|
| 1 | 新着記事が画像のみ（タイトルなし） | notion | `mobile-shared.css` で 1024px 以下 Flexbox リスト。Grid に戻さない |
| 7 | サムネとタイトルが重なる | notion | 同上 + `.notion-root` スコープ |
| 8 | 画像のみ表示 | zapier | `ZapierArticleCard.tsx` + `zapier.css` 横リスト |

**教訓:** ランキングは Flexbox で正常、記事リストだけ崩れる → カードの `display:grid` と `overflow:hidden` を疑う。修正は **左96pxサムネ + 右テキストの Flexbox** が定石。

### 2. カテゴリタブ縦書き崩れ

| # | タイトル | テーマ | 対策の要点 |
|---|---------|--------|-----------|
| 2 | タブが1文字ずつ縦並び | notion | `section-header` を grid 化、タブは2行目全幅+横スクロール |
| 9 | 同上 | wired | `wired.css` 1200px 以下で同様の grid 化 |

**教訓:** `flex-wrap` だけでは不十分。`flex-shrink:0` + `white-space:nowrap` + 専用行が必要。

### 3. メルマガバナー縦書き

| # | タイトル | テーマ | 対策 |
|---|---------|--------|------|
| 6 | バナー文言が縦積み | 全テーマ | `writing-mode: horizontal-tb`、`min-width:0`、flex 横並び |

### 4. デプロイ・インフラ

| # | タイトル | 対策 |

**教訓:** 完了報告前に `npm run verify:sites`（exit 0）。Tunnel 直 200 だけでは不十分。

## データ更新方法

```bash
# 一覧を再エクスポート
npm run platform:seed

# 新規登録
python3 platform_meta/seed.py --register-bug \
  --title "..." --symptom "..." --root-cause "..." --fix "..." \
  --themes notion,wired,zapier --commit <hash>
```

登録後は本ファイルの該当セクションも更新すること。
